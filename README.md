# Saint-Seiya-price

圣斗士星矢手办 · 日本现货购买与收藏指南

## 使用方式

- 下载或直接使用浏览器打开 `index.html`，无需安装依赖。
- 手机端单列卡片，桌面端双列卡片。
- 商品价格下方固定显示成色、瑕疵及报价说明，无需展开；点击商品名称展开参考图、库存来源、原图及销售链接。每日更新时保持此布局，避免在详情中重复显示说明。
- 支持中日文关键词搜索、库存记录和独立网上购买状态筛选，三者可组合；预算清单同步复用购买状态及链接。
- 商品价格下方显示网购状态；已确认网购商品另列直达商品的具体价格、成色、核查日期。优先链接实际商品页，原门店挂牌列表保留供比价。
- 收藏预算区可展开11位/12位黄金圣斗士及青铜五小强的商品清单，点击名称查看图片和购买入口；自动复用主目录数据，不重复维护价格及链接。
- 官方新品预约与抽选独立置于收藏预算之前，含官方图、原价及人民币参考、预约方式、开始/截止时间、结果公布、发售/发货时间、官方入口、独立状态筛选。不会计入现货数量或收藏预算。
- 全站商品参考图（官方新品、收藏预算、全部主目录分类）点击后均在当前网页弹出放大预览；关闭按钮、点击遮罩及 Esc 均可退出，官方资料、预约、打开原图、购买链接仍独立保留。
- 网页 favicon 使用仓库内的 `favicon.ico`（16/32/48 px）。

## 网购状态与每日维护规则

2026-11-27 本次单独复核27款具体销售页的购物车/购买入口（黄金十二宫12款、青铜五小强5款均有入口），15款由门店列表补充直达页；6款未来发售、5款现货/网购待核实。未实际下单，不承诺实时库存。原挂牌区间与预算沿用本次改版前的调查快照；直达商品价格单独注明（不一定是区间最低价），按原参考汇率换算人民币。

- 每张主目录卡片保留稳定ID、`data-state`、`data-search`、独立 `data-buy` 及价格下方唯一一段 `buy-info`，预算组自动克隆。网购状态为 online（具体商品页显示可购入口）、pending（挂牌但未核实网购）、unverified（现货/网购未核实）、future（未来发售）、out（明确无可购买现货）。
- 仅在同版本具体销售页有购买/加购入口且无缺货/已售提示时使用 online；标明 `data-buy-date`、确切报价及成色。不可把门店列表、官方定价、已售记录当成当前网上可购买。网页无法复核时保留旧报价、链接及核查日期，但标为 pending 或 unverified，不列为当日已核实网购。具体销售页优先作为 primary，原挂牌列表保留为 secondary；更新需同时核对其价格和成色，不得误用最低瑕疵价。
- 每次更新检查全部商品都有有效购买状态、状态文案与数据一致、网购筛选及库存筛选组合有效、预算克隆与主目录一致、价格下方说明不重复、统计由目录计算、响应式及原图/购买链接保持。网购状态独立于挂牌区间和预算，不擅自把所有门店挂牌价当作可直接购买报价。
